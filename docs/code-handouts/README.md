## 建议的敲写顺序

**不要一次性全写完再跑。** 中间有三个自然的休整点：

```
01 → 02 → 03        会话记忆这一层做完（25 绿）
  ↑ 休整点：此时你可以用单测确认"窗口裁剪 + 摘要"是对的，代码还跑不起来

04                  接上模型和 HTTP 端点
  ↑ 休整点：此时你有一个能用的多轮流式助手了，先用 curl 玩一会儿

05 → 06             长期记忆这一层做完（45 绿）
  ↑ 休整点：端到端验收 —— 新会话里主动用上偏好

07                  收尾
```

**先写到 04 就停下来玩一玩。** 多聊几轮、试试重启后历史还在不在、看看摘要在第 21 轮之后有没有生效。这一步能让你对"会话记忆"建立手感，再往"长期记忆"走会踏实很多。

每章通过 REST 端点验收（`mvn spring-boot:run` + curl）。模型走**自建注册表**（对齐 ai-common 的 `ModelRegister`：
yml `ai.models.*` → `ModelRegistrar` → AgentScope `ModelRegistry`，agent 里 `.model("fast")` 按名引用），
**不用 agentscope starter**，**不接 ai-common / ai-memory**（学习舱，隔离才能学清）。版本锁定 AgentScope **2.0.4**。
